Windows x64 版本，增加 DeepSeek 官方 API 接入，将原固定 GLM 入口改为可选择 GLM / DeepSeek 的“模型 API”入口。

安装包不包含用户 Key、官方账号凭据或本机配置。在同一 Windows 用户下升级并沿用原 Codex Home，可以保留已有档案；换电脑请重新填写 Key。

## 主要更新

- 总览仍保留四个切换入口：OpenAI、API1、API2，以及可选择 GLM / DeepSeek 的模型 API。改变选择器只切换展示档案，点击“切换”才改写 Codex 路由。
- 内置 DeepSeek 官方地址 `https://api.deepseek.com`，使用原生 Responses 协议；默认 `deepseek-flash`（文字/图片），另含 `deepseek-v4-pro`（文字）。模型名称可编辑。
- GLM / DeepSeek 独立保存加密 Key、模型目录与供应商设置。旧 GLM 配置自动保留，已有 API1/API2 档案不受影响。
- 首次部署、配置预览及调整、按供应商恢复默认、Qt/Tk 界面与实际请求监控均支持 DeepSeek。
- DeepSeek 使用自己的 API Key，不删除官方账号登录文件；进入前保存所需兼容字段，离开时恢复，清理 Fast mode 与 AP1 专用图像字段，避免污染其他供应商。
- 健康监控读取真实 Codex 请求；Token 统计按事件增量和供应商切换时间归属，继续支持时间范围、M 单位和千分位。未配置套餐额度接口时不显示 DeepSeek 额度按钮，不新增按量余额或消费金额展示。
- 包含 1.3.10 的默认配置调整：恢复默认时移除自定义 `[features.multi_agent_v2]` 提示段，普通切换仍保留用户无关配置。

## 开始使用 DeepSeek

1. 在“供应商配置”选择 DeepSeek，保留内置官方地址，填写自己的有效 API Key，选择模型后保存。
2. 在总览“模型 API”中选择 DeepSeek，再点击“切换”。
3. 返回 GLM 时选择 GLM 并点击切换；两者的 Key、模型目录及 GLM 团队额度设置独立保留。
