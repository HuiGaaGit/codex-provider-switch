## 功能

- 对官方 DeepSeek 地址自动接入 `GET https://api.deepseek.com/user/balance`，携带 DeepSeek 自身的 Bearer Key，显示币种、可用总余额、赠送余额、充值余额、可调用状态与查询时间。
- 总览“查余额”与供应商配置“仅查询余额”均使用已保存的凭据；未使用 DeepSeek 或未选模型时也可查询，不切换、不写 config/auth、不重启、不调用模型。
- 官方地址兼容 `/v1` 基址。自定义 API 地址需要显式填写兼容余额接口，避免把中转 Key 自动发送到官方。旧 1.3.11 档案自动兼容，无需重新部署。
- Decimal 保留金额精度，以千分位和两位小数显示。CNY / USD 分开显示，不画没有总额度依据的百分比，不计算消费金额。其他供应商的钱包显示策略不变。
- 查询失败显示具体类别，不将空数据当零余额，不显示虚假的“已更新”，不回显服务端敏感原文或 Key。
- 配置刷新保留手动查询结果；改变 Key 或地址后，旧请求的结果不会用于新配置。
- 移除监控导航、监控页面、Token 仪表盘及总览监控统计，停止自动扫描会话/请求日志和监控通知。保留托盘驻留、手动链路测试、GLM/API1/API2 额度查询和既有切换、部署、配置编辑流程。旧日志及本地凭据不删除。
