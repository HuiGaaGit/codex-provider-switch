# DeepSeek 官方余额查询（1.3.12）

## 目标与依据

按 https://api-docs.deepseek.com/api/get-user-balance/ 接入 `GET https://api.deepseek.com/user/balance`，使用 DeepSeek 自身的 Bearer Key，解析 `is_available` 及 `balance_infos` 中的币种、可用总余额、赠送余额、充值余额。

余额与套餐额度、Token 统计、真实请求健康分开。官方没有返回套餐总量，不绘制余额百分比，不推算消费；只增加 DeepSeek 余额，不恢复其他供应商的按量金额展示。

## 实施步骤

1. 增加独立余额数据、Decimal 金额解析、官方默认地址及自定义地址边界；兼容 1.3.11 已保存档案。
2. 复用仅查询入口，未使用 DeepSeek 或未选模型时也可查余额；不写 config/auth、不切换、不重启、不发起模型请求。
3. Qt/Tk 显示“查余额”和币种金额明细。按追加需求移除监控页面、导航及后台监控触发，保留托盘驻留和手动余额/额度、链路测试；余额查询不代表模型健康。
4. 覆盖零余额、多币种、异常数据、认证/网络失败、旧档案及界面回归；使用临时 Codex Home，不输出真实 Key。
5. 递增为 1.3.12，保留旧包，更新文档并打包；验证启动、托盘与安装/卸载。没有真实 DeepSeek Key 时明确实测边界。

## 安全边界

- 默认仅对官方 `api.deepseek.com` 使用官方余额地址；自定义供应商地址需要显式填写余额接口，不能把其 Key 自动送到官方。
- 查询失败不展示“已更新”，不以空响应伪造零余额或可用状态；错误信息不包含认证头、Key 或原始敏感响应。
- 不修改用户当前供应商连接，不访问无关凭据，不执行真实推理请求。
- 原功能实现为本地交付；用户随后明确授权推送 1.3.12、更新 README 并提供 GitHub 安装包下载。发布新的 v1.3.12，不覆盖 v1.3.11 或旧产物。
